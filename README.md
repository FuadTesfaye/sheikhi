# Sheikh Muhammed Hamdu — Official Website

الشيخ محمد حمدو رشو

Official website of Sheikh Mohamed Hamdu Rasho — Islamic scholar, teacher, Imam and Khateeb of Masjid Abu Bakr, Addis Ababa.

## About

This is the official digital archive and website for Sheikh Muhammed Hamdu, built to answer:

- **Who** is Sheikh Muhammed Hamdu?
- **What** did he study?
- **Where** did he receive his qualifications?
- **Where** has he taught or worked?
- **What** does he teach?
- **Where** can you listen to or watch him?

## Features

- 📖 Complete biography and educational journey
- 🎓 Qualifications & certificate gallery with fullscreen viewer
- 🕌 Teaching positions and service history
- 📚 Fields of knowledge
- 🎬 Embedded YouTube lectures
- 📱 TikTok short reminders
- 📞 Contact information
- 📱 Fully responsive (mobile-first)
- 🔍 SEO optimized

## Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS 4
- **Animation**: Framer Motion (minimal, editorial)
- **Icons**: Lucide React + custom SVG icons
- **Runtime**: Bun
- **Fonts**: Manrope, Inter, Noto Naskh Arabic

## Getting Started

```bash
# Install dependencies
bun install

# Run development server
bun dev

# Build for production
bun run build

# Start production server
bun start
```

## Design Principles

- **Scholarly, not flashy** — editorial design that respects the subject
- **Credibility first** — every claim backed by documents
- **Mobile-first** — optimized for phone users
- **Minimal animation** — subtle fade-in, no distractions
- **Clean typography** — Manrope for English, Noto Naskh Arabic for Arabic
